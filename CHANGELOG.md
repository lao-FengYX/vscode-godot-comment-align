# Change Log

All notable changes to the "godot-comment-align" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.1] - 2025-01-06

### Added

- Initial release of Godot Comment Align
- One-click format & align for GDScript files
- Automatic comment alignment after native formatting
- Smart grouping of consecutive comment lines
- Configurable comment indent size (`godotCommentAlign.commentIndentSize`)
- Output channel logging for debugging
- Keybinding `Shift+Alt+F` for GDScript files
